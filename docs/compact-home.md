# Компактний головний екран

Затверджений світлий стиль №5. Дев’ять розділів і 100 рекомендацій, фото, чотири характеристики та п’ять нижніх кнопок залишаються доступними. Замість описів — короткі назви, без випадкових розривів слів. Версія і авторство фото залишені у програмі. Прокрутка дозволена у підменю та як запасний варіант на надзвичайно низьких екранах або при збільшеному системному шрифті, щоб не приховувати функції. CI перевіряє відсутність вертикального переповнення головної на 320×568, 360×640, 390×740, 390×844, 480×844 CSS px. Фізичний пристрій потребує перевірки.
