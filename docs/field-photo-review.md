# Практичні фотографії

Десять реальних файлів з Wikimedia Commons, переглянуті окремо та зіставлені з темою інструкції. Оригінальні байти без редагування вбудовуються під час CI. Підписи і ліцензії відображаються біля кожного фото. Приклади не заявлені як вимірювання UTi260B. Для e2 — блок запобіжників, для f2 — не підтверджена несправність, для r2 — лише арифметичний приклад різниці між неоднорідними матеріалами, для r3 — пара кадрів, не акт. Розміри перевіряються перед вбудовуванням; CI записує SHA-256 та робить скриншоти. Авторські права на окремі ілюстрації виробника все ще потребують перевірки.

### Доповнення перевірки
MPO (фото f1) — контейнер JPEG із допоміжними кадрами; оригінальні байти залишаються незмінними, браузер має декодувати основний кадр. Тест перевіряє кожний екран за ширини 320, 390, 480 CSS px, декодування зображень, збільшення, імпорт тестового фото, пошук і збереження обраного. Фізичний Android-пристрій не тестувався.
