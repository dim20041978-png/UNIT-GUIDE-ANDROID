# UNI-T — Онлайн-інструкція 1.0.0
Незалежний україномовний Android-довідник UTi260B. Мінімальна версія Android 6.0. Пакет ua.thermoguide.unit. Офлайн: локальний HTML, пошук, обране, перегляд доступних зображень через системний вибір файлів. Онлайн: зовнішні посилання на документацію та відео. Прямий USB-обмін, радіометричний аналіз, автоматичне оновлення матеріалів, 100 рекомендацій та реальні фото меню не реалізовані в стартовій версії.

## Збірка
Створіть окремий репозиторій UNIT-GUIDE-ANDROID, завантажте весь вміст архіву (включно з `.github/workflows/build.yml`) у корінь main. GitHub Actions → Build UNI-T Guide APK → Run workflow або автоматичний запуск після push. Після успішного завершення завантажте artifact UNI-T-Guide-1.0.0-debug, розпакуйте його та встановіть APK. Це debug-підпис, не релізний. Для стабільного оновлення потрібен постійний власний ключ підпису.
Локально: JDK 17, Gradle 8.7, Android SDK 35, `gradle assembleDebug lintDebug`.

## Перевірка
Локальний HTML можна відкрити в браузері без збірки (кнопка виходу лише в Android). Перед публікацією перевірити на реальному телефоні: запуск, усі категорії, пошук, обране після перезапуску, назад, вихід, зовнішні посилання, BMP/JPEG/PNG, офлайн. Збірка та тест на пристрої ще не виконані.
